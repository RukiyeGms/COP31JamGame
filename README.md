
# Sunny Fish Rescue

A cozy 2D underwater cleanup game created for **GameUp Türkiye Oyun Hackatonu**.

## About the Game

Dive into an underwater adventure where you collect trash, rescue endangered fish, and learn about marine life through a fish discovery Codex.

You have **30 seconds per day** to help clean the ocean. Play through seven days, then continue your cleanup journey for as long as you like!

## Features

- Underwater trash collection and fish rescue
- Click-based fish rescue minigame
- Educational Codex featuring endangered fish species
- Daily scores and progress saved at the end of each completed day
- Seven-day progression with an option to continue playing
- Illustrated introduction and How to Play guide

## Controls

| Input | Action |
| --- | --- |
| Right mouse button | Move your character |
| Left mouse button | Interact with trash and fish |
| Repeated left clicks | Rescue trapped fish |
| Esc | Pause / resume |

## Play

**Platform:** Windows

Download the Windows build from our itch.io page. Extract the ZIP file and run the game's `.exe` file.
